# FSU theme token mapping

Reference for `web/src/styles/themes/fsu-light.css` and `fsu-dark.css`. Brand hex values come from the FSU visual style guide; shadcn roles are assigned for UI contrast and accessibility.

| Brand color | Hex | Typical role |
| --- | --- | --- |
| FSU Garnet | `#782F40` | `--primary`, `--ring` |
| FSU Gold | `#CEB888` | `--accent` (dark text on gold in light mode) |
| White / Gulf Sands tint | `#FFFFFF` / `#DFD1A7` family | Warm off-white `--background` (light); pure white avoided on canvas |
| Stadium Night | `#101820` | `--foreground` (light), `--background` (dark) |
| Plaza Brick | `#572932` | Brand gradient endpoint only (dark theme) |
| Gulf Sands | `#DFD1A7` | `--muted`, `--secondary` (light theme) |
| Legacy Blue | `#425563` | `--muted`, `--surface-cool` influence (dark theme) |
| Westcott Water | `#5CB8B2` | `--info`, `--category-sky` (sparingly) |

Gradients follow guide pairings: Garnet → Plaza Brick.
