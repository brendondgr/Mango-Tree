# Utils Shared

Cross-app foundations shared by all modules under `utils/apps/`.

## Subdirectories

| Directory | Role |
| --- | --- |
| `auth/` | Authentication utilities |
| `permissions/` | Permission policies and enforcement |
| `storage/` | S3-compatible object storage |
| `search/` | Search utilities |
| `embeddings/` | Embedding generation and management |
| `events/` | Event recording and activity history |

See `docs/skills/django-backend/`.
