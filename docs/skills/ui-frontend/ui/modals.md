# Modals And Dialogs

Use dialogs for focused decisions that interrupt a workflow, such as confirming cancellation, viewing a log excerpt, or editing scoped runtime settings.

## Rules

- Keep modals narrow and task-specific.
- Provide a clear title, close control, and primary action.
- Trap focus while open and restore focus when closed.
- Use `--overlay-bg` for modal backdrops.
- Do not put large navigation flows inside modals.
