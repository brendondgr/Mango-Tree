# Colors And Themes

Use the Pulse Light theme for Mango Tree.

```css
.theme-pulse-light {
  --bg-color: #F4F6F9;
  --bg-secondary: #EAF6FB;
  --surface-color: #FFFFFF;
  --text-primary: #25284B;
  --text-secondary: #475569;
  --text-muted: #64748B;
  --accent: #20588D;
  --accent-light: #40B1D7;
  --accent-dark: #153A5D;
  --border-color: #D6E4F0;
  --overlay-bg: rgba(32, 88, 141, 0.85);
  --overlay-text: #FFFFFF;
  --shadow-color: rgba(37, 40, 75, 0.1);
  --table-header-bg: #D6E4F0;
  --table-row-alt: #F4F6F9;
  --status-success: #10b981;
  --status-danger: #dc2626;
}
```

## Rules

- Use `--accent` for primary actions and selected navigation.
- Use `--accent-light` for hover, charts, and secondary emphasis.
- Use `--accent-dark` for high-contrast text on light blue surfaces.
- Use success and danger colors only with labels or icons.
- Keep backgrounds light and surfaces white.
