# Typography

Use clean system typography for the initial shell. Prefer legibility over personality until the product surface is mature.

## Rules

- Body text must be at least `16px`.
- Headings should be compact inside dashboards and panels.
- Do not scale font size directly with viewport width.
- Use tabular numerals for metrics, counts, durations, and run IDs.
- Keep paragraph line length below `75ch`.
- Preserve semantic heading order.
