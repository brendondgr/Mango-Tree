# Buttons And Interactive Elements

Buttons should be compact, legible, and predictable.

## Rules

- Primary actions use `--accent` with white text.
- Secondary actions use white surfaces, `--border-color`, and `--text-primary`.
- Destructive actions use `--status-danger` and explicit labels.
- Minimum touch target is `44px` by `44px`.
- Use icons for common tool actions when the app icon set is introduced.
- Keep focus states visible with the shared `:focus-visible` outline.
