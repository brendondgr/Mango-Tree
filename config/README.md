# Config

Project configuration for Django and the agent runtime.

## Layout

| Path | Purpose |
| --- | --- |
| `django/` | Django settings, URLs, WSGI, ASGI |
| `models.yaml` | Model provider configuration |
| `agents.yaml` | Agent definitions |
| `tools.yaml` | Tool registry |
| `permissions.yaml` | Permission policies |
| `workflows.yaml` | Workflow manifests |

See `docs/skills/repo-structure/structures/django-apps.md`.
