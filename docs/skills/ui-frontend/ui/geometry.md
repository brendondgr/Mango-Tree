# Layout And Geometry

Mango Tree should feel like a precise operations interface.

## Rules

- Use 8px or smaller border radii for cards and panels.
- Use full-width page bands with constrained inner content.
- Do not nest cards inside cards.
- Keep repeated items in stable grids or tables.
- Use responsive constraints so toolbars, counters, tiles, and buttons do not shift size unexpectedly.
- Keep mobile layouts single-column until there is enough width for comparison views.
