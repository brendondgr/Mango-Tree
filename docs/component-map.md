# Component Map

Frontend source lives in `web/src/`.

| Area | Path | Purpose |
| --- | --- | --- |
| Pages | `web/src/pages/` | Astro route files. |
| Layouts | `web/src/layouts/` | Shared document and page shells. |
| Layout components | `web/src/components/layout/` | Navigation, app shell, sidebars, headers. |
| UI components | `web/src/components/ui/` | Reusable buttons, badges, cards, tables, controls. |
| Feature components | `web/src/components/feature/` | Agent-runtime specific views and panels. |
| Styles | `web/src/styles/` | Theme tokens and global CSS. |

The current setup creates only minimal structural components.
